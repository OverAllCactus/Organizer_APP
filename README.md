# Organizer_APP
### Органайзер на Python.

## Запуск:
1. Установите Python 3
2. Скачайте проект из репозитория
3. Откройте терминал в корне проекта
4. Установите необходимые пакеты командой pip install aiohttp / Установите зависимости с помощью UV
5. Запустите приложение командой python organizer_app.py / uv run organizer_app.py
